# あAマーカー

macOSの現在の入力モードを画面上のフローティングバッジで表示するアプリです。

## ダウンロード

[Releases](https://github.com/pupepa/InputModeMarker/releases)からDMGファイルをダウンロードしてください。

## 動作環境

- macOS 26.2以降
- Apple Silicon / Intel対応

GitHubが表示する「Source code」はソースコードです。インストールにはDMGを使用してください。

## インストール

1. ダウンロードしたDMGを開きます。
2. `あAマーカー.app` を `Applications` へドラッグします。
3. アプリケーションフォルダから「あAマーカー」を起動します。
